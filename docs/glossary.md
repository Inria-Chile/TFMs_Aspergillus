# Glossary

- **AUC**: area under the receiver operating characteristic curve.
- **CLR**: centred log-ratio transformation for compositional microbiome data.
- **F1**: harmonic mean of precision and recall.
- **FDR**: false discovery rate.
- **MAE**: mean absolute error.
- **PySR**: Python interface to SymbolicRegression.jl.
- **RF**: Random Forest.
- **RMSE**: root mean squared error.
- **SHAP**: SHapley Additive exPlanations; predictor contributions to a model output.
- **TFM**: tabular foundation model.
- **TabICLv2**: the second version of the Tabular In-Context Learning model.
- **TabPFN**: Tabular Prior-Data Fitted Network.
- **XGBoost**: Extreme Gradient Boosting.

The repository uses TFM as the general category and TabPFN/TabICLv2 for
individual foundation models. TFM should not be abbreviated as TFN.
